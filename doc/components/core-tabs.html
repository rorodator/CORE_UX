<core-tabs> slot event

Accessible tablist with declarative <core-tab> labels and <core-tab-panel> bodies. Keyboard: arrows, Home, End.

Companion tags: <core-tab>, <core-tab-panel> — captured from light DOM on first render.
Tag / attributeValuesDescription
core-tabs · valuestringActive tab key (required).
core-tabs · layoutpills · underlineVisual style (default: pills).
core-tab · valuestringTab key (required).
core-tab · labelstringVisible tab label.
core-tab · disabledbooleanNon-interactive tab.
core-tab-panel · valuestringPanel key matching a tab (required).

Event: core-tabs-change — detail.value, detail.previousValue.

Method: setTabLabel(value, label) — update a tab label after capture (e.g. i18n).

Changing value programmatically syncs the UI without emitting core-tabs-change.
