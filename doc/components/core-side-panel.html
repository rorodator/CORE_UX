<core-side-panel> slot event

Slide-over drawer from any edge. Toggle with the open attribute. Closes on backdrop, ×, or Escape.

Same overlay/surface tokens as core-modal — see Theming.
Attribute / patternValuesDescription
openbooleanShow / hide panel.
titlestringPanel title (aria-labelledby).
aria-labelstringAccessible name when no visible title is provided.
positionleft · right · top · bottomEdge to slide from (default right).
sizesm · lg · fullWidth (left/right) or height (top/bottom).
data-core-footer—Footer slot (same as card / modal).

Event: core-side-panel-close — detail.reason: backdrop · close · escape.

Provide either a non-empty title or aria-label. An unnamed panel emits a console warning and no visible fallback text is invented. On open, the panel remembers the active element, moves focus inside, traps Tab and Shift+Tab, closes on Escape, and restores focus when closed. Changes to title, position, and size update in place so slotted form state and current focus are preserved.

Open by position

Click a button to open the drawer from that edge.

Close reason will appear here.
<core-button id="open" label="Open filters"></core-button>
<core-side-panel id="drawer" title="Filters" position="right">
  …body…
  <div data-core-footer>…</div>
</core-side-panel>

document.getElementById('open').addEventListener('click', () => {
  document.getElementById('drawer').setAttribute('open', '');
});
drawer.addEventListener('core-side-panel-close', (e) => {
  console.log(e.detail.reason);
});
