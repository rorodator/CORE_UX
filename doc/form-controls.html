Shared form attributes

Common to core-field, core-textarea, core-select, core-checkbox, and core-radio-group.

AttributeTypeDescription
labelstringVisible label (<legend> on radio group).
hintstringHelper text; linked via aria-describedby.
errorstringValidation message; adds error styling and aria-invalid.
namestringForm field name on inner control.
valuestringInitial value.
input-idstringExplicit control id (auto-generated if omitted).
requiredbooleanHTML required.
disabledbooleanDisables control.
placeholderstringfield and textarea only.
