<core-autocomplete-chips>

Multi-select autocomplete with removable chips. Inherits autocomplete API and events.

AttributeDefaultDescription
max-chips—Maximum selected items.
uniquetruePrevent duplicate values (unique="false" to allow).
chips-positionaboveabove or below the input.
clear-on-selecttrueClear input after adding a chip.
item-label-key / item-value-key—Custom object keys for label/value.
Plus all core-autocomplete attributes.
Chip attrs (max-chips, unique, …) are read once on connect — set before insertion or recreate the element to change them.

Events

chips-change, chips-add, chips-remove (+ inherited autocomplete-*)

Basic multi-select

Selected values appear here.
<core-autocomplete-chips label="Skills" min-characters="1"></core-autocomplete-chips>
el.setDataSource([{ title: 'JavaScript', value: 'js' }, ...]);
el.addEventListener('chips-change', (e) => console.log(e.detail.values));

Max chips & chips below

<core-autocomplete-chips max-chips="3" chips-position="below"></core-autocomplete-chips>

Pre-selected values

el.setSelected([
  { title: 'News', value: 'news' },
  { title: 'Sports', value: 'sports' }
]);

Additional API

setSelected, getSelectedValues, getSelectedItems, add, remove, clearSelection, setChipsPosition, setItemLabelGetter, setItemValueGetter
