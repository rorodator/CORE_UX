Theming

CORE_UX components read semantic CSS custom properties (--core-*). Override them on .core-ux-root — no kit rebuild. Full reference: THEMING.md.

Live presets

Switch palette below — only CSS variables change, not component markup.

Preset: default
/* app-theme.css — after CORE_UX/dist/core-ux.css */
.core-ux-root {
  --core-color-primary: #6366f1;
  --core-color-primary-hover: #4f46e5;
  --core-radius: 0.5rem;
  --core-font-family: "Inter", system-ui, sans-serif;
}

/* Optional built-in dark palette */
.core-ux-root[data-core-theme="dark"] { /* see THEMING.md */ }

App integration checklist

  1. Add class="core-ux-root" on <body> (or app shell).
  2. Import CORE_UX/dist/core-ux.css, then your theme file.
  3. Override only --core-* variables — avoid patching .core-* rules.
  4. Toggle data-core-theme="dark" for the built-in dark palette, or define your own.
