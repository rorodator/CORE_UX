<core-radio-group>

Fieldset of radio buttons from JSON options.

AttributeValues / defaultDescription
nameautoShared radio name (defaults to field id).
optionsJSON array{ value, label, selected? }
layoutstack · inlineVertical (default) or horizontal layout.
Plus shared form attributes.

Stack layout (default)

<core-radio-group
  label="Shipping method"
  name="shipping"
  options='[{"value":"standard","label":"Standard"},{"value":"express","label":"Express","selected":true}]'
></core-radio-group>

Inline layout

<core-radio-group label="Size" layout="inline" options="..."></core-radio-group>

Required with error

<core-radio-group label="Payment" required error="Select a payment method." options="..."></core-radio-group>
