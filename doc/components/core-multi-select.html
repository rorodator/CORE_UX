<core-multi-select>

Dropdown multi-select (collapsed by default): click or focus the trigger to open a searchable checkbox panel. Each row can be plain text, label + image, or custom HTML.

AttributeDefaultDescription
options[]JSON array (see option shape below).
value—Selected values as JSON array or comma-separated string.
searchabletrueShow search field (set searchable="false" to hide).
search-placeholderSearch…Search input placeholder.
max-visible6Option rows visible in the list (toolbar height is added on top).
max-height—CSS length override for the whole block (panel or inline).
empty-searchNo matchesMessage when filter returns nothing.
show-countfalseDisplay “N selected”.
select-allfalseButtons: Select visible / Clear all.
placeholderSelect…Trigger text when nothing is selected (dropdown mode).
always-openfalseKeep the full list visible (no collapsed trigger).
floatingtruePortal dropdown panel to document.body (set floating="false" to keep in-flow).
Default: dropdown — collapsed trigger; panel opens on focus/click.
Plus shared form attributes (form controls).

Option shape

{
  "value": "fr",
  "label": "France",
  "selected": false,
  "image": "https://…/fr.png",
  "imageAlt": "France",
  "description": "Optional subtitle",
  "keywords": "extra search terms",
  "trustedHtml": "<span class='badge'>Custom</span>",
  "disabled": false
}

If trustedHtml is set, it replaces the default label/image layout for that row. This is an author-controlled markup API only: it does not sanitize HTML and must never receive unsanitized user input or API data. Use label and description for those values. Legacy key html is still accepted as an alias.

Keyboard and ARIA

The component uses one listbox focus model. Opening focuses search when present; Arrow Down enters the listbox. Without search, opening focuses the listbox directly. In the listbox, Arrow Down/Arrow Up move the active option, Home/End move to the first/last enabled option, and Enter or Space toggles selection. Escape closes the dropdown and returns focus to its trigger. The listbox exposes aria-activedescendant, and every option exposes aria-selected. Checkboxes are visual selection indicators and are not separate keyboard stops.

Events

multiselect-change · multiselect-select · multiselect-deselect · multiselect-open · multiselect-close

API

open() · close() · toggle() · getSelectedValues() · getSelectedItems() · setSelected(values) · setOptions(options) · clearSelection() · selectVisible()

Inside overflow container

With floating (default), the panel is portaled to document.body so it is not clipped by scrollable parents.

Scroll this box — the dropdown should stay fully visible. 

<!-- floating is true by default -->
<core-multi-select floating="true" …></core-multi-select>

Dropdown mode (default)

Collapsed trigger — focus or click to open. Closes on outside click, Escape, or when focus leaves.

<core-multi-select
  label="Languages"
  options='[{"value":"en","label":"English","selected":true}, …]'
></core-multi-select>
