Getting started

Install the kit, import components, rebuild CSS when styles change.

Installation

Symlink CORE_UX in your app and add a bundler alias:

CORE_UX → ../CORE/CORE_UX
CORE_JS → ../CORE/CORE_JS

Import

// Full kit (all components + CSS)
import 'CORE_UX/index.js';

// Or curated subset in app entry (e.g. core-ux-myjourney.js)
import 'CORE_UX/components/core-button/core-button.js';
import 'CORE_UX/dist/core-ux.css';

CSS build

cd CORE_UX
npm install
npm run build    # styles/core-ux.css → dist/core-ux.css
Rebuild after changing styles/ or component class names.

Theming

All kit visuals use semantic CSS custom properties (--core-*). Apps override them on .core-ux-root at runtime — no rebuild of CORE_UX required. 

<body class="core-ux-root">

/* app-theme.css — after CORE_UX/dist/core-ux.css */
.core-ux-root {
  --core-color-primary: #6366f1;
  --core-radius: 0.5rem;
}

Full token reference: Theming (doc + live demo) · THEMING.md.

Viewing this documentation

Demos use ES modules and import maps. Serve the repo over HTTP:

cd CORE_UX
php -S localhost:8765 -t .
# → http://localhost:8765/doc/

Architecture

Base classComponentsRole
Core_UXElementMost tagsExtends Core_HTMLElement; ui_render() builds DOM.
Core_UXSlotElementcontainer, stack, grid, card, modalCaptures light-DOM children before render.
Core_UXFormControlfield, textarea, select, checkbox, radio-groupLabel, hint, error, ARIA wiring.

Lifecycle

  1. onConnect() → this.render()
  2. render() → ui_render() then ui_toFunctional()
  3. cleanFunctional() on disconnect

Conventions

DOM helpers

Shared DOM utilities live in CORE_JS — import the module or use $svc('dom') when AppCore is bootstrapped:

import { createElement, mountHtml, hasBoolAttr } from 'CORE_JS/lib/utils/dom.js';

$svc('dom').createElement('button', { text: 'Save', attrs: { type: 'button' } });

Boolean attributes

Present and not "false" → true. Remove the attribute to disable (not disabled="false").

JSON attributes

options on select/radio expects [{ "value", "label", "selected"? }].

Footer slot

core-card and core-modal extract a child with data-core-footer.

Form shared attributes: Form controls.
