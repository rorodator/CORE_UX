<core-link>

Styled anchor for in-app and external navigation.

AttributeDescription
hrefURL (default #).
labelLink text (falls back to href).
externalOpens in new tab with rel="noopener noreferrer".

Internal links

<core-link href="/dashboard" label="Dashboard"></core-link>
<core-link href="/settings" label="Settings"></core-link>

External link

<core-link href="https://example.com" label="Example.com" external></core-link>

Label fallback

When label is omitted, the href is shown as text.

<core-link href="mailto:support@example.com"></core-link>
