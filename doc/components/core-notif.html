<core-notif-host> · <core-notif>

Viewport corner toasts — stacked with configurable offsets. Unlike core-alert (inline banner), these float above the page.

Semantic tokens match core-alert — Theming reference

core-notif-host

AttributeDefaultDescription
positiontop-endtop-start · top-end · bottom-start · bottom-end
offset-top1remDistance from top viewport edge (CSS length).
offset-bottom1remDistance from bottom edge.
offset-left1remDistance from left edge.
offset-right1remDistance from right edge.
gap0.5remSpace between stacked toasts.

Portals to document.body while connected. API: show(options), clear().

core-notif

AttributeDefaultDescription
variantinfoinfo · success · warning · error
message—Plain text body (never user HTML).
duration5000Auto-dismiss delay in ms; 0 = manual only.
dismissibletrueShow × button (dismissible="false" to hide).

Events: core-notif-show · core-notif-close (bubbles). Method: close().

Imperative API

Click to push toasts on the host above (top-right, below doc header offset).

const host = document.getElementById('my-notif-host');
host.show({ variant: 'success', message: 'Saved.', duration: 4000 });
host.show({ variant: 'error', message: 'Failed.', duration: 0 }); // manual dismiss

Custom offsets

Bottom-left host with larger margins — open several to see stacking.

<core-notif-host position="bottom-start"
  offset-bottom="2rem" offset-left="2rem" gap="0.75rem"></core-notif-host>

Declarative child

Optional: place <core-notif> inside the host (moved into the stack on connect).

<core-notif-host position="top-end">
  <core-notif variant="info" message="Hello" duration="8000"></core-notif>
</core-notif-host>
