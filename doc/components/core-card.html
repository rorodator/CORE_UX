<core-card> slot

Content card with optional header and footer (data-core-footer).

Attribute / patternDescription
titleCard heading.
subtitleSubtitle under title.
Light DOMBody content.
data-core-footerChild extracted into footer region.

Title only

You have 3 unread messages.

 
<core-card title="Notifications">
  <p>You have 3 unread messages.</p>
</core-card>

Title + subtitle

<core-card title="Profile" subtitle="Public information">
  <core-field label="Display name" value="Jane Doe"></core-field>
</core-card>

With footer actions

All associated data will be permanently removed.

 
<core-card title="Confirm delete">
  <p>…</p>
  <div data-core-footer>
    <core-stack direction="row" gap="2" justify="between">
      <core-button variant="ghost" label="Cancel"></core-button>
      <core-button variant="danger" label="Delete"></core-button>
    </core-stack>
  </div>
</core-card>
