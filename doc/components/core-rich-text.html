<core-rich-text>

WYSIWYG rich-text editor with toolbar presets, plain-text maxlength, localized toolbar, and HTML sanitization helpers. Shared form attrs.

AttributeDefaultDescription
min-height8Editor minimum height in rem.
maxlength—Optional plain-text limit (UTF-16 code units). Applies to getText(), not HTML length. Sets aria-invalid when exceeded.
toolbarfullfull, narrative (no alignment), or compact (minimal inline tools).
sanitizetrueWhen not false, output is whitelist-sanitized on read, paste, and when setting value.
Plus shared form attributes (label, hint, error, name, value, …).

Events

EventdetailWhen
core-rich-text-input{ html, text, maxLengthExceeded }While typing, formatting, or pasting (bubbles).
core-rich-text-change{ html, text, maxLengthExceeded }On editor blur (bubbles).

Public API

MethodReturnsDescription
getHtml()stringSanitized HTML (unless sanitize="false").
getText()stringPlain text — reference for maxlength.
setHtml(html)voidSets editor content; sanitizes by default.
isMaxLengthExceeded()booleanTrue when plain text exceeds maxlength.

HTML helpers

Import from CORE_UX/lib/html/rich-text-html.js (re-exported by the component module):

  • escapeHtml(text) — escape plain text for HTML contexts.
  • sanitizeRichTextHtml(html) — whitelist sanitizer (client).
  • sanitizeRichTextPaste(html, plainText) — paste-safe sanitizer.
  • normalizeRichTextHtml(html) — sanitize + remove empty blocks.
  • getPlainTextFromHtml(html) / getRichTextPlainLength(html) — plain text extraction and length.
Always sanitize again on the server before persisting or rendering stored HTML. PHP apps can use Core\Util\RichTextHtml::sanitize() in CORE_PHP.

Sanitization contract

Allowed tags: p, br, strong, em, u, lists, links, span/div with color or text-align only. Rejects script, iframe, img, on* handlers, javascript:, data:, and arbitrary CSS.

i18n

Consuming apps keep their own data-core-lang on the host (e.g. field label, placeholder). Internal toolbar and link-dialog hooks carry separate data-core-lang entries (container core_ux). Reference catalogues: lang/labels-{en,fr,es,de}.json. See components/core-rich-text/README.md.

Toolbar presets

PresetTools
fullBold, italic, underline, lists, link, color, alignment, clear formatting.
narrativeSame without alignment — posts and stories.
compactBold, italic, underline, link, clear formatting.
