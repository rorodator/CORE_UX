<core-autocomplete>

Combobox with local array or async data source. Keyboard: ↑ ↓ Enter Escape.

AttributeDefaultDescription
placeholderType to search...Input placeholder.
label—Visible label.
min-characters3Min query length.
delay300Debounce (ms).
max-results10Max items (local filter).
allow-additionsfalseFree-text entry on Enter.
force-selectionfalseRevert blur if not from list.
clearablefalseShow clear button.
no-resultsNo resultsEmpty state text.
disabledfalseDisable input.
floatingtruePortal results list to document.body (set floating="false" for in-flow).

Events

autocomplete-select, autocomplete-search, autocomplete-results, autocomplete-open, autocomplete-close, autocomplete-focus, autocomplete-blur, autocomplete-change

Inside overflow container

With floating (default), the results list escapes scrollable parents via a body portal — same pattern as core-multi-select.

Scroll this box — suggestions should not be clipped. 

<core-autocomplete floating="true" …></core-autocomplete>

Local data source

Select a city to see the event.
el.setDataSource([
  { title: 'Paris', value: 'paris', description: 'France' },
  { title: 'Berlin', value: 'berlin', description: 'Germany' }
]);
el.addEventListener('autocomplete-select', (e) => console.log(e.detail.result));

Allow additions

Type a name not in the list and press Enter.

<core-autocomplete allow-additions="true" min-characters="1"></core-autocomplete>

Force selection

Blur reverts to the last selected value.

<core-autocomplete force-selection="true"></core-autocomplete>

Async function source

el.setDataSource(async (query) => {
  await new Promise((r) => setTimeout(r, 300));
  return users.filter((u) => u.title.toLowerCase().includes(query.toLowerCase()));
});

Public API

setDataSource, configure, preConfigure, getValue, setValue, clear, focus, blur, enable, disable, setLoading, performSearch, updateResults
