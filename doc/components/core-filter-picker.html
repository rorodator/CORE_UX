<core-filter-picker>

Search-first catalog. The text field is the control; typing filters and opens the tree. Browse opens the full tree, or the tree already limited by the current text. The picker does not know filter instances and does not build a form.

Pass definition records to setEntries(). A record uses id, label, description, keywords, group (Trading / Dates) or groupPath, disabled, and visible. visible: false is omitted. A disabled row stays visible and cannot be chosen. Search ignores case and accents and matches the label, description, keywords, and category path. A match keeps its ancestor categories. There is no debounce and no extra form.
AttributeValues / defaultDescription
labeltextVisible name of the field. Default Add a filter. An empty value removes the visible label and names the field Search filters.
placeholdertextDefault Search filters.
button-labeltextBrowse button text. Default Browse.
openbooleanTree is open. Absent means closed.
disabledbooleanDisables the field and the button and closes the tree.
querytextInitial search text. The live value is the query property.
keep-querybooleanAfter a choice, keep the typed text. Without it, the field is cleared.

Keyboard

From the field: ArrowDown and ArrowUp open the tree and move through enabled rows, wrapping at the ends. Home and End jump while the tree is open. Enter chooses the highlighted row, or opens the tree when it is closed. Escape closes and keeps the text. Tab closes and moves focus onward. The tree does not trap Tab. Disabled rows are skipped.
