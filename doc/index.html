CORE_UX

Shared UI kit for CORE-based apps: 20 custom elements, mobile-first CSS, pure DOM rendering. Each component has its own page with live demos and copy-paste examples.

Quick start

import 'CORE_UX/index.js';

<core-button variant="primary" label="Save"></core-button>
Open these pages via a local HTTP server (ES modules). From the repo root: php -S localhost:8765 -t . then visit http://localhost:8765/doc/.

See Getting started for installation, architecture, and conventions. Customise colours and typography via Theming (--core-* CSS variables).
