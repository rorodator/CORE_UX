At core-alert — CORE_UX

<core-alert>

Banner with semantic colour variants and optional dismiss.

AttributeValues / defaultDescription
variantinfo · success · warning · errorColour scheme (default: info).
messagestringAlert body text.
dismissiblebooleanShow dismiss button.

Event: core-alert-dismiss (bubbles) — host gets hidden.

All variants

<core-alert variant="info" message="Your profile is 80% complete."></core-alert>
<core-alert variant="success" message="Changes saved successfully."></core-alert>
<core-alert variant="warning" message="Your session expires in 5 minutes."></core-alert>
<core-alert variant="error" message="Unable to connect to the server."></core-alert>

Dismissible

Dismiss event will appear here.
<core-alert variant="info" message="..." dismissible></core-alert>
el.addEventListener('core-alert-dismiss', () => { /* … */ });
