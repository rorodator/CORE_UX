<core-range-field>

Two text bounds for a minimum and a maximum. One side may be empty. This is not a slider and not a calendar. Shared form attrs. Format attributes match core-formatted-field.

Both inputs are type="text", named {name}-min and {name}-max, with accessible names Minimum and Maximum. The group is labelled by the visible label. Bounds stack on a narrow viewport and sit on one row from the sm breakpoint. A partial range is valid. If both sides are set and the minimum is greater than the maximum, the raw text stays, value is removed, and the error code is E_RANGE_ORDER.
