<core-rich-text>

WYSIWYG rich-text editor with toolbar formatting and HTML sanitization helpers. Shared form attrs.

AttributeDefaultDescription
min-height8Editor minimum height in rem.
sanitizetrueWhen not false, output is whitelist-sanitized on read and when setting value.
Plus shared form attributes (label, hint, error, name, value, …).

Events

EventdetailWhen
core-rich-text-input{ html, text }While typing or formatting (bubbles).
core-rich-text-change{ html, text }On editor blur (bubbles).

Public API

MethodReturnsDescription
getHtml()stringSanitized HTML (unless sanitize="false").
getText()stringPlain text extracted from the editor.
setHtml(html)voidSets editor content; sanitizes by default.

HTML helpers

Import from CORE_UX/lib/html/rich-text-html.js (re-exported by the component module):

  • escapeHtml(text) — escape plain text for HTML contexts.
  • sanitizeRichTextHtml(html) — whitelist sanitizer (client).
  • normalizeRichTextHtml(html) — sanitize + remove empty blocks.
  • getPlainTextFromHtml(html) — plain text extraction.
Always sanitize again on the server before persisting or rendering stored HTML. PHP apps can use Core\Util\RichTextHtml::sanitize() in CORE_PHP.

Toolbar

Bold, italic, underline, bullet/numbered lists, link, text color, alignment (left/center/right), clear formatting.

Default

<core-rich-text label="Notes" placeholder="Write your thoughts…"></core-rich-text>

With initial value

<core-rich-text label="Summary" value="<p>Hello <strong>world</strong></p>"></core-rich-text>
