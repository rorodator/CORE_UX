<core-menu> composable event

Dropdown menu with a trigger label and live <core-menu-item> / <core-menu-separator> children. Closes on outside click, Escape, or Tab. Arrow keys navigate items when open.

Tag / attributeValuesDescription
core-menu · labelstringTrigger text (required).
core-menu · alignstart · endPanel alignment (default: end).
core-menu · openbooleanShow / hide panel.
core-menu · disabledbooleanDisable trigger.
core-menu-item · valuestringItem key (required).
core-menu-item · labelstringStatic fallback when light-DOM body is empty.
core-menu-item · disabledbooleanSkip item in keyboard nav and block selection.
core-menu-item · data-core-langJSONOn the host; child defaults to the inner label hook.
core-menu-separator—Horizontal rule between items (role="separator").

Events: core-menu-select — detail.value. Also core-menu-open / core-menu-close.

Methods: openMenu(), closeMenu(), toggleMenu(), setLabel(label), refresh() (after dynamic children).

Keyboard: trigger — ↓ / Enter / Space opens; ↑ opens and focuses last item; panel — ↑↓ move, Home / End, Escape closes.

User menu (align end)
