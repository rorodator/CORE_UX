<core-tooltip>

Accessible hover/focus tooltip wrapper with four placements and viewport flip.

AttributeValues / defaultDescription
textstringTooltip body (required unless disabled).
positiontop · bottom · left · rightPreferred placement (default: top). Flips when overflowing the viewport.
delayms (default 200)Show delay after hover or focus.
hide-delayms (default 100)Hide delay after pointer/focus leaves.
disabledbooleanSuppress tooltip and aria-describedby.

Slot: trigger content (e.g. a core-button or icon). Events: core-tooltip-show, core-tooltip-hide (bubble). Press Escape to dismiss while open.

Placements

Hover or focus each button

<core-tooltip text="Shown above the trigger" position="top">
  <core-button variant="secondary" label="Top"></core-button>
</core-tooltip>

Long text & delays

<core-tooltip text="..." position="bottom" delay="400" hide-delay="150">
  <core-button variant="primary" label="Hover me"></core-button>
</core-tooltip>

Disabled

<core-tooltip text="..." disabled>
  <core-button variant="secondary" label="No tooltip"></core-button>
</core-tooltip>

Events

Show/hide events appear here.
el.addEventListener('core-tooltip-show', () => { /* … */ });
el.addEventListener('core-tooltip-hide', () => { /* … */ });
