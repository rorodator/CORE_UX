<core-select>

Native select populated from a JSON options attribute.

AttributeDescription
optionsJSON: [{ "value", "label", "selected"? }]. Host value also selects an option.
Plus shared form attributes.

Basic options

<core-select
  label="Country"
  options='[{"value":"fr","label":"France"},{"value":"de","label":"Germany"}]'
></core-select>

Pre-selected option

options='[..., {"value":"pro","label":"Pro","selected":true}]'

Selected via value attribute

<core-select label="Timezone" value="utc" options="..."></core-select>

With hint & error

<core-select label="Role" hint="Choose your primary role." options="..."></core-select>
<core-select label="Role" error="Please select a role." options="..."></core-select>
