Filter bar examples

The minimal catalog, an advanced bar with formats and an option provider, and a parent that only listens to state$ and events$. Nothing here loads rows from an application service.

Tag reference: core-filter-bar. The engine note in CORE_JS is ai-instructions/filter-engine.md. These pages do not add a query language, a grid, or a data backend.

Minimal catalog

Four definitions. No callback, no provider, no adapter. Labels and operators are inferred.

Formats and an option provider

Amount uses a French decimal format. The stored value stays the exact canonical string. Trade date uses dd MMM yyyy. City options arrive from a function that receives AbortSignal.

Parent subscriber

This block is the only consumer. It reads state$, events$, and getCriteria(). It does not own the editors and it does not fetch rows. events$ stays empty until the bar changes.

RxJS

state$ replays the current state on subscribe. events$ does not. A change publishes state first, then the events of that commit. State and events share the same revision. Events also carry a transactionId and the corresponding state snapshot. Construction and initialFilters do not emit. destroy() completes both streams. Removing the element from the page does not.
